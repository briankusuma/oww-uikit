Card

Cards are versatile, modular surfaces used to group and organize related information, media, and interactive actions. Built in strict alignment with design system specifications for Confirmation / Dialog Cards and e-commerce Product Cards.

Overview

The Deleted Confirmation Card component is designed for critical decision points and modal confirmations. It features a bold title header with a circular close action, a subtle horizontal divider line, descriptive body copy, and a right-aligned footer button group for user confirmation.

Confirmation Dialog Card

The Confirmation Card features a 20px border radius, 20px internal padding, 1px subtle stroke, and an elevated shadow (0px 4px 40px rgba(0, 0, 0, 0.16)). It adapts cleanly for multiple confirmation use cases.

Product Card

The Product Card component is engineered for e-commerce, catalog, and inventory displays. It features a media slot with a 120px height, product information hierarchy, price badge, and interactive states including hover elevation, a floating action button (three dots), and an image fallback state.

Design Tokens Mapping

All visual styles in Card reference registered SCSS design tokens defined with !default flags.

Element Token SCSS Resolved Value
Card Background -bg #FFFFFF
Confirmation Card Border -border-color #E4E4E4
Product Card Border -border-color-product #C4C4C4
Confirmation Card Radius -radius-dialog 20px
Product Card Radius -radius-product 14px
Media Box Radius -media-radius 10px
Dialog Internal Padding -padding-dialog 20px (-6)
Product Internal Padding -padding-product 12px (-3)
Dialog Drop Shadow -shadow-dialog 0 4px 40px rgba(0, 0, 0, 0.16)
Product Hover Shadow -card-hover 0 1px 8px rgba(0, 0, 0, 0.08)
Close Button Size -close-btn-size 40px × 40px
Action Button Size -action-btn-size 32px × 32px

Architecture & Rules

Guidelines and SCSS architecture for integrating the Card component into your application. 

// 1. SCSS Import
"token-keyword\">@use "src/scss/components/card";

// 2. Custom Token Override Example
"token-keyword\">@use "src/scss/abstract/variables" with (
  $card-radius-dialog: 24px,
  $card-border-color: #d1d5db
);
