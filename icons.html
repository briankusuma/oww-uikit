Icons & Flags

Official iconography system of OWW Design System encompassing 55 UI Icons (110 Outline & Fill variants) alongside 260 Country Flags (total 370 icons).

Overview

All icons and flags are built on a standard 20px × 20px grid base to ensure visual consistency and rhythm across all OWW platforms.

Category Count Grid Base Color Characteristics Design Source
UI Icons 110 (55 Outline, 55 Fill) 20×20px Monochrome currentColor (theme adaptive) UI Icons Component Set
Country Flags 260 Countries 20×20px Official Multi-color Circular Vectors Country Flags Component Set

Usage & Implementation

OWW UIKit icons can be implemented directly as inline SVG (recommended for dynamic color theming and animation) or referenced as external SVG files. 

<!-- 1. UI Icon as Inline SVG (Inherits parent text color via currentColor) -->
<span style="color: var(--doc-primary);">
  <svg width="20" height="20" viewBox="0 0 20 20" fill="none">
    <path d="..." fill="currentColor"/>
  </svg>
</span>

<!-- 2. Country Flag as CSS Icon Tag -->
<span class="oww-icon--flag-indonesia" style="width: 20px; height: 20px;"></span>
