Avatar

The Avatar component represents user entities, teams, or profile identities. Crafted with precision following official Figma specifications for Avatar and Initials Avatar component systems.

Overview

Avatars support three primary display variants: Image, Initials, and Placeholder (Fallback). The component comes in 4 standardized size scales: xs (22px), sm (32px), md (40px), and lg (48px).

Image (48px)
MA
Initials (48px)
Placeholder (48px) 
<!-- Image Avatar -->
<div class="oww-avatar oww-avatar--lg">
  <img src="avatar.png" alt="User" class="oww-avatar__image">
</div>

<!-- Initials Avatar -->
<div class="oww-avatar oww-avatar--lg oww-avatar--initials">
  <span class="oww-avatar__initials">MA</span>
</div>

<!-- Placeholder Avatar -->
<div class="oww-avatar oww-avatar--lg oww-avatar--placeholder">
  <img src="placeholder.png" alt="Placeholder" class="oww-avatar__image">
</div>

Architecture & Rules

The Avatar component is cleanly isolated in src/scss/components/_avatar.scss and exported to the master stylesheet src/scss/uikit.scss. 

// src/scss/uikit.scss
@forward 'abstract/variables';
@forward 'abstract/functions';
@forward 'abstract/mixins';

@use 'base/reset';
@use 'base/typography';
@use 'base/layout';

@use 'components/alert';
@use 'components/avatar';  // <-- Avatar Component
@use 'layout/docs';
