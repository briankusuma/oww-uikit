Alert

Provide contextual feedback messages for typical user actions. Built with high precision following Figma design specifications.

Overview

The Alert component adheres to BEM architecture with class name .oww-alert. Designed with border radius 12px, padding 12px, Inter 14px Medium typography, and a 20×20px icon.

Lorem ipsum dolor sit amet consectetur adipiscing elit

<div class="oww-alert oww-alert--success" role="alert">
  <div class="oww-alert__content">
    <span class="oww-alert__icon" aria-hidden="true">...</span>
    <p class="oww-alert__text">Lorem ipsum dolor sit amet consectetur adipiscing elit</p>
  </div>
</div>

Figma Variants

Official variants defined in the Figma component design: Success and Warning.

Variant=Success: Operation completed successfully.

Variant=Warning: Please double check your campaign budget settings.

<!-- Success Variant -->
<div class="oww-alert oww-alert--success" role="alert">...</div>

<!-- Warning Variant -->
<div class="oww-alert oww-alert--warning" role="alert">...</div>

Full Width Modifier

Use the .oww-alert--full class to expand the alert width to 100% of its parent container.

Your ad campaign changes have been saved and synchronized globally.

<div class="oww-alert oww-alert--success oww-alert--full" role="alert">
  <div class="oww-alert__content">...</div>
</div>

Extended System Variants

Additional extended variants integrated into the OWW system tokens: Danger (Error) and Info.

Variant=Danger: A server processing error occurred.

Variant=Info: New platform version updates are now available.

<!-- Danger Variant -->
<div class="oww-alert oww-alert--danger" role="alert">...</div>

<!-- Info Variant -->
<div class="oww-alert oww-alert--info" role="alert">...</div>

All visual styles in Alert reference registered SCSS design tokens defined with !default flags.

Architecture & Rules

This component adheres strictly to AGENT.md guidelines. Component styles are isolated in src/scss/components/_alert.scss and imported via src/scss/uikit.scss. 

// src/scss/uikit.scss
@forward 'abstract/variables';
@forward 'abstract/functions';
@forward 'abstract/mixins';

@use 'base/reset';
@use 'base/typography';
@use 'base/layout';

@use 'components/alert';
@use 'components/avatar';
@use 'layout/docs';
