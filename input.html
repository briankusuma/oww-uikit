Input & Forms

Contextual form controls, single-line text inputs, badge chip collections, multiline textareas, phone number pickers, date dropdowns, and shareable link fields.

Overview

The Form Input component adheres to BEM architecture with class name .oww-input. Form controls feature standard 56px height (Large) and 48px (Medium), rounded corners, placeholder styling, and responsive focus states.

*
Enter a descriptive title for your advertising campaign.
Branding Performance
Press Enter or comma to add a tag. Click X or press Backspace to remove.
<!-- Standard Form Input Group -->
<div class="oww-form-group">
  <div class="oww-form-group__label-row">
    <label for="campaignTitle" class="oww-form-group__label">Campaign Title</label>
    <span class="oww-form-group__required">*</span>
  </div>
  <input type="text" id="campaignTitle" class="oww-input" placeholder="e.g. Summer Mega Sale 2026">
  <div class="oww-form-group__hint">Enter a descriptive title for your advertising campaign.</div>
</div>

Sizes Scale

Form inputs are available in two standard sizing scales: Large (56px) for primary desktop cards and forms, and Medium (48px) for compact layouts and mobile devices.

*
* 
<!-- Large Input (Default 56px, Radius 14px) -->
<input type="text" class="oww-input" placeholder="Placeholder...">

<!-- Medium Input (48px, Radius 12px) -->
<input type="text" class="oww-input oww-input--md" placeholder="Placeholder...">

Design Tokens Mapping

All visual styles in Form Input reference registered SCSS design tokens defined with !default flags.

Input Background (Default) $input-bg-default #F8F8F8
Input Border (Default) $input-border-color-default #E9E9E9
Input Focus Ring $input-focus-shadow 0 0 0 1px #000000
Input Background (Disabled) $input-bg-disabled #F1F1F1
Input Border (Disabled) $input-border-disabled #C4C4C4
Input Background (Error) $input-bg-error #FFE9EC
Input Border (Error) $input-border-error #FF0909
Height Large (56px) $input-height-lg 56px
Height Medium (48px) $input-height-md 48px
Radius Large (14px) $input-radius-lg 14px
Radius Medium (12px) $input-radius-md 12px
Typography @include text('sm', 'regular') Inter, 14px, 400, -0.02em

Architecture & Rules

This component adheres strictly to AGENT.md guidelines. Component styles are isolated in src/scss/components/_input.scss and imported via src/scss/uikit.scss. 

// src/scss/uikit.scss
@use 'components/input';
