Dropdown

Dropdowns present contextual menus, selection pickers, country search overlays, and multi-criteria filters. Built in strict alignment with Figma specifications featuring 14px rounded containers, 10px rounded menu items, custom scrollbars, and smooth elevations.

Overview

An interactive dropdown with a trigger button that toggles an overlay menu. Selecting an option updates the trigger value automatically. 

<div class="oww-dropdown">
  <button type="button" class="oww-dropdown__trigger" aria-haspopup="true">
    <span class="oww-dropdown__trigger-text">Select Month</span>
    <svg viewBox="0 0 20 20" fill="none"><path d="M5 7.5L10 12.5L15 7.5" stroke="currentColor" /></svg>
  </button>

  <div class="oww-dropdown__menu oww-dropdown__menu--scrollable" role="menu">
    <button type="button" class="oww-dropdown__item" role="menuitem">
      <span class="oww-dropdown__item-text">January</span>
    </button>
    <button type="button" class="oww-dropdown__item" role="menuitem">
      <span class="oww-dropdown__item-text">February</span>
    </button>
  </div>
</div>

Design Tokens

All design tokens mapped to Dropdown component specifications from Figma.

Token Name SCSS Variable Value Description
dropdown.bg $dropdown-bg #FFFFFF Default dropdown menu surface color
dropdown.border $dropdown-border-color #E4E4E4 (1px) Menu outer border stroke
dropdown.radius $dropdown-radius 14px Container corner radius
dropdown.padding $dropdown-padding 8px ($spacing-2) Container internal padding
dropdown.shadow $dropdown-shadow 0 1px 8px rgba(0,0,0,0.12) Elevation drop shadow
dropdown.item.radius $dropdown-item-radius 10px Corner radius for menu items
dropdown.item.height $dropdown-item-height 37px Fixed height for each menu item row
dropdown.item.hover $dropdown-item-hover-bg #F8F8F8 Background on item hover state
dropdown.divider $dropdown-divider-color #F1F1F1 Divider line separating groups

Architecture & Rules

Guidelines and SCSS architecture for integrating the Dropdown component into your application. 

// 1. SCSS Import
@use "src/scss/components/dropdown";

// 2. Custom Token Override Example
@use "src/scss/abstract/variables" with (
  $dropdown-radius: 16px,
  $dropdown-item-radius: 12px
);
