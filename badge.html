Badge

Badges are compact status, categorical, count, and interactive indicator tags. Designed with high fidelity from Figma specifications for Input Badges, Text Categories, Verified Seals, Unread Counters, and Image Pagination indicators.

Overview

The Badge design system provides 4 specialized functional variants designed for diverse UI requirements:

Input Badge (Filter Tags)

Input Badges are used as interactive filter chips, email recipient pills, or selected tag items. They feature an integrated close/dismiss button and support Default, Hover, and Disabled states.

Image Pagination Badge

Floating pill indicator engineered for carousels, media viewers, and image galleries. Features a pure white background, subtle border, and elevation box shadow (0px 0px 8px rgba(0, 0, 0, 0.2)) for clear contrast against diverse image backgrounds.

Architecture & Rules

The Badge component is modularly encapsulated in src/scss/components/_badge.scss and compiled into the master bundle dist/uikit.css. 

// src/scss/uikit.scss
@forward 'abstract/variables';
@forward 'abstract/functions';
@forward 'abstract/mixins';

@use 'base/reset';
@use 'base/typography';
@use 'base/layout';

@use 'components/alert';
@use 'components/avatar';
@use 'components/badge';  // <-- Badge Component System
@use 'layout/docs';
