Button

Buttons trigger actions and choices with a single tap or click. Built in strict alignment with Figma specifications supporting Primary, Outline, Ghost, Danger Soft, and Verification Badge variants across 4 standard sizes (xs, sm, md, lg).

Overview

Explore the core button styling tiers designed for clear visual hierarchy across applications:

Primary
Outline
Ghost
Danger Soft
Verification 
<!-- Primary Action -->
<button type="button" class="oww-btn oww-btn--primary oww-btn--md">Primary Button</button>

<!-- Outline Secondary Action -->
<button type="button" class="oww-btn oww-btn--outline oww-btn--md">Outline Button</button>

<!-- Ghost Subtle Action -->
<button type="button" class="oww-btn oww-btn--ghost oww-btn--md">Ghost Button</button>

<!-- Danger Action -->
<button type="button" class="oww-btn oww-btn--danger oww-btn--sm">Delete</button>

<!-- Verification Badge Button -->
<button type="button" class="oww-btn oww-btn--verification oww-btn--sm">
  <span class="oww-btn__text">Get a verification badge</span>
  <span class="oww-btn__icon"><img src="./dist/assets/icons/badge-verified-business.svg" alt=""></span>
</button>

Sizes Scale

Buttons are available in 4 standard heights: xs (26px), sm (32px), md (40px), and lg (48px).

xs (26px)
sm (32px)
md (40px) - Default
lg (48px) 
<button class="oww-btn oww-btn--primary oww-btn--xs">Extra Small</button>
<button class="oww-btn oww-btn--primary oww-btn--sm">Small</button>
<button class="oww-btn oww-btn--primary oww-btn--md">Medium</button>
<button class="oww-btn oww-btn--primary oww-btn--lg">Large</button>

Core Variants

The button system is divided into three primary functional tiers: Primary (solid black), Outline (light grey border), and Ghost (borderless). 

<button class="oww-btn oww-btn--primary oww-btn--md">Primary Variant</button>
<button class="oww-btn oww-btn--outline oww-btn--md">Outline Variant</button>
<button class="oww-btn oww-btn--ghost oww-btn--md">Ghost Variant</button>

Interactive States

Buttons include complete visual representations for Default, Hover, Pressed/Active, Focus Ring, and Disabled states.

Default
Hover (#434343)
Pressed
Disabled (#D9D9D9) 
<!-- Default state -->
<button class="oww-btn oww-btn--primary oww-btn--sm">Default</button>

<!-- Forced hover state class or native :hover -->
<button class="oww-btn oww-btn--primary oww-btn--sm is-hover">Hover</button>

<!-- Pressed state class or native :active -->
<button class="oww-btn oww-btn--primary oww-btn--sm is-pressed">Pressed</button>

<!-- Disabled button -->
<button class="oww-btn oww-btn--primary oww-btn--sm" disabled>Disabled</button>

Buttons with Icons

Pair buttons with icons on the left or right to enhance visual clarity and context. 

<!-- Left Icon Button -->
<button class="oww-btn oww-btn--primary oww-btn--md">
  <span class="oww-btn__icon"><svg ...></svg></span>
  <span class="oww-btn__text">Add Item</span>
</button>

<!-- Right Icon Button -->
<button class="oww-btn oww-btn--outline oww-btn--md">
  <span class="oww-btn__text">Continue</span>
  <span class="oww-btn__icon"><svg ...></svg></span>
</button>

Icon-Only Buttons

Circular icon-only buttons formatted for toolbars, actions, and media control. Includes the circular Delete Icon button with trashcan asset. 

<!-- Circular Icon-Only Button (Outline) -->
<button class="oww-btn oww-btn--outline oww-btn--md oww-btn--icon-only" aria-label="Action">
  <span class="oww-btn__icon"><svg ...></svg></span>
</button>

<!-- Delete Icon Button (Danger Soft) -->
<button class="oww-btn oww-btn--danger oww-btn--sm oww-btn--icon-only" aria-label="Delete item">
  <span class="oww-btn__icon"><svg ...></svg></span>
</button>

Danger Soft (Delete Button)

A soft danger aesthetic featuring a soft pink background (#FFE9EC), light danger border (#FFC7CB), and red action text (#FF0909). 

<button type="button" class="oww-btn oww-btn--danger oww-btn--sm">
  <span class="oww-btn__icon"><svg ...></svg></span>
  <span class="oww-btn__text">Delete</span>
</button>

Verification Badge Button

A promotional call-to-action button highlighting account certification, with soft green background (#E9F6E7) and official verified badge icon. 

<button type="button" class="oww-btn oww-btn--verification oww-btn--sm">
  <span class="oww-btn__text">Get a verification badge</span>
  <span class="oww-btn__icon">
    <img src="./dist/assets/icons/badge-verified-business.svg" alt="Verified" width="16" height="16">
  </span>
</button>

Design Tokens

All button properties are linked directly to Figma tokens defined in src/scss/abstract/_variables.scss.

Element / Variant Figma Property SCSS Variable Output Value
Primary Background Fills $color-base-black-500 #000000
Primary Hover Fills #434343 #434343
Primary Disabled Fills #D9D9D9 #D9D9D9
Outline Background Fills $color-base-grey-100 #F8F8F8
Outline Border Stroke 1px Solid $color-base-primary-100 #E9E9E9
Danger Background Fills $bg-soft-danger #FFE9EC
Danger Border Stroke 1px Solid $color-border-danger #FFC7CB
Danger Text / Icon Fills $color-base-danger-500 #FF0909
Verification Background Fills $bg-soft-success #E9F6E7
Button Radius Border Radius $radius-full 100px (Pill / Circular)

Architecture & Rules

The Button component is isolated in src/scss/components/_button.scss and compiled into dist/uikit.css. 

// src/scss/uikit.scss
@forward 'abstract/variables';
@forward 'abstract/functions';
@forward 'abstract/mixins';

@use 'base/reset';
@use 'base/typography';
@use 'base/layout';

@use 'components/alert';
@use 'components/avatar';
@use 'components/badge';
@use 'components/button';  // <-- Button Component System
@use 'layout/docs';
